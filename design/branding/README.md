# Approved input artwork

- `approved-wordmark.png` is the supplied “Elegant Qissa Logo with Bookish Flourish.png”.
- `approved-q.jpg` is the standalone long-tail Q referenced in the supplied saved HTML
  and confirmed by the user for SVG/favicon use.

These inputs are kept unchanged. Final transparent logos and icons are generated
under `static/branding/` by `scripts/build_brand_assets.cjs` using deterministic
vector traces. The wordmark and standalone Q are intentionally separate approved
sources, as requested. No text/font substitution is involved.
